# Workshop RisingWave: cấu hình môi trường

`docker/` chứa cấu trúc cấu hình monitoring đi kèm RisingWave (Prometheus, Grafana, `risingwave.toml`, `dashboards/`).

> Hiện tất cả các mục trong `docker/` là **thư mục rỗng** (kể cả những mục đặt tên như file như `prometheus.yaml`, `risingwave.toml`), nên chưa dùng được. Lấy cấu hình gốc từ [risingwave-data-talks-workshop-2024-03-04](https://github.com/risingwavelabs/risingwave-data-talks-workshop-2024-03-04) rồi chép vào đây.

Bài tập chạy trên môi trường này nằm ở [../workshop-02](../workshop-02).
